# hover-lang 🛸

**The Hover Programming Language**

Hover is a mixed-systems co-simulation language that combines logic (software-style computation) with physical (circuit) descriptions in a single source file. It is designed to serve as an unified, high-performance alternative to MATLAB/Simulink and SPICE.

https://hover-lang.org/
