# hover-lang 🛸

**The Hover Programming Language**

Hover is a mixed-systems co-simulation language that combines logic (software-style computation) with physical (circuit) descriptions in a single source file. It is designed to serve as a unified, high-performance alternative to MATLAB/Simulink and SPICE.

### 🚧 Status: v0.3 (Under Development)
* **Release Timeline:** Will be open source and ready to use in the summer.
* **Availability:** Only binaries will be released until the first reliable version is achieved.
